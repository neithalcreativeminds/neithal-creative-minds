NEITHAL CREATIVE MINDS - COMPLETE STARTER

1. Extract this folder to C:\neithal-creative-minds
2. Open the folder in Visual Studio Code.
3. Open Terminal -> New Terminal.
4. Run: npm install
5. Run: npm run dev
6. Open: http://localhost:3000

This project intentionally uses JavaScript only. Do not create tsconfig.json, next-env.d.ts, .ts files or .tsx files.

Included:
- Frozen Model 1 visual direction
- Responsive navigation
- Hero / About / Services / Work / Process / Reviews / Contact / Footer
- Working client-side enquiry form demo
- Working local AI assistant demo
- Call and WhatsApp floating buttons
- Company logo in public/logo.png

The enquiry form and AI assistant are frontend/demo functionality. A production deployment should connect the enquiry form to an email/database/API and connect the AI assistant to a real AI API when those integrations are ready.
